THE REVIEW

WHY IT SCORES WELL

The Pro plan gives unlimited code completion and next edit suggestions for $10 a month. Paid plans also add third-party agents such as Claude Code and Codex.

Admin and security score lower, since SAML SSO and IP indemnity sit outside the individual plans.

WHO IT'S FOR

Developers and teams who work in Visual Studio Code, Visual Studio or the terminal and want one assistant across them.

STANDOUT FEATURES

  • Agent mode is included on every individual plan, Free included.
  • Runs reusable agent tasks on demand, on a schedule or from triggers.
  • Finds code quality and security issues before you open a pull request.
  • Adds the MCP servers, skills and plugins you choose.
  • Lets you pick a specific model or let Copilot match models to tasks.

INTEGRATIONS

Visual Studio Code, Visual Studio, the terminal/CLI, MCP servers and third-party coding agents from Anthropic and OpenAI.

PROS / CONS

Pros:

  • Free plan includes agent mode.
  • Pro costs $10 with unlimited completions.
  • Wide model choice, including Opus on Pro+.

Cons:

  • No SAML SSO on individual plans.
  • No IP indemnity on individual plans.
  • Delegating tasks to third-party agents (Preview) needs Pro+ or Max.
  • Business plan prices are not shown in page text.

FAQ

FAQs about GitHub Copilot

Is GitHub Copilot free?

Yes, there is a free plan. It includes 2,000 completions per month, agent mode and models such as Haiku 4.5 and GPT-5 mini.

How much does GitHub Copilot Pro cost?

Pro costs $10 per user per month. It adds unlimited code completion, next edit suggestions and access to Claude Code and Codex agents.

Does GitHub Copilot support SSO?

Not on individual plans. The plans page marks SAML SSO as not included on Free, Pro, Pro+ and Max. Check the business plans on the vendor pricing page.

Which editors does GitHub Copilot work in?

The vendor lists Visual Studio Code and Visual Studio among its IDEs. Copilot also runs in the terminal through its CLI.

Can GitHub Copilot use MCP servers?

Yes. You can find MCP servers, skills and plugins, then add the ones you choose.
