Pi

Pinecone

Best for managed RAG search

Pinecone is a fully managed vector database with hybrid search, hosted reranking and the strongest admin controls in this list.

9.6/10 Visit Pinecone

Why we picked it

Pinecone scores full marks on search features, entry access and admin controls. Its docs cover hybrid search, tenant namespaces, hosted reranking and integrated embedding, and the pricing page lists SSO, audit logs, CMEK, private endpoints and SOC 2.

Who it's for

Teams that want production RAG search without running database servers themselves.

Standout features

  • Hybrid search: it "indexes the text for full-text search and embeds it for semantic search."
  • Namespaces per tenant: "each namespace is stored separately", giving physical isolation between tenants.
  • Hosted reranking: hosted reranking models handle two-stage retrieval on one platform.
  • Metadata filtering: filtering "narrows the candidate pool before ranking".

Integrations

Integrations include LangChain, LlamaIndex, Haystack, n8n, Zapier, Vercel, OpenAI and Cohere, per Pinecone's integrations docs.

Pricing

As of Nov 2026, Starter is free, Builder is $20/month flat, Standard $50/month minimum usage, Enterprise $500/month minimum; BYOC is by quote.

Pros

  • Builder is a flat $20 a month, no minimum.
  • RBAC and SAML SSO start on the Standard plan.
  • BYOC runs Pinecone inside your own cloud account.

Cons

  • We found no self-hosted option in its docs.
  • Audit logs, CMEK and private endpoints need Enterprise.
  • BYOC pricing is "Contact us" only.

Weaviate

Best open source with built-in embeddings

Weaviate is an open-source vector database that builds embeddings for you and runs in its cloud, yours, or on your servers.

9.5/10 Visit Weaviate

Why we picked it

Weaviate takes full marks on search, deployment and entry access. It runs as Weaviate Cloud or self-managed, offers "built-in vector generation", and has a free cluster plus Flex from $45 a month.

Who it's for

Developers who want open-source vector search without building a separate embedding pipeline.

Standout features

  • Hybrid search: it fuses vector and BM25F keyword results into one ranked list.
  • MMR reranking: Maximal Marginal Relevance reranks results to balance relevance with diversity.
  • Multi-tenancy: "Each tenant is stored on a separate shard", invisible to other tenants.
  • Built-in vectorizers: text and images become vectors with "no external embedding pipeline required."

Integrations

Model integrations include OpenAI, Anthropic, Cohere, Google, AWS, Mistral, Hugging Face and Ollama, per Weaviate's model provider docs.

Pricing

As of Nov 2026, Free is $0 for one cluster, Flex starts at $45/mo pay as you go, and Premium is by sales.

Pros

  • RBAC is included on every plan, Free too.
  • Self-host it or use Weaviate Cloud.
  • Weaviate Cloud is SOC 2 audited.

Cons

  • We found no audit logs in its docs.
  • SSO needs Premium; customer keys need Premium dedicated.
  • Flex carries a $45 monthly minimum.

Qdrant

Best for self-hosting and hybrid cloud

Qdrant is a vector database you can run in its cloud, on your own Kubernetes, or fully air-gapped on your own servers.

9.0/10 Visit Qdrant

Why we picked it

Qdrant scores full marks on search and deployment. Its Hybrid Cloud lets you "bring your own Kubernetes", Private Cloud supports air-gapped setups, and its query API fuses dense and sparse search with re-scoring.

Who it's for

Platform teams that must keep vector data on their own infrastructure or Kubernetes clusters.

Standout features

  • Hybrid queries: you can fuse any combination of queries, then re-score candidates with a richer vector.
  • Filtered search: filters apply during the HNSW search phase, not only afterwards.
  • Tiered multitenancy: tenants share collections by payload field; large ones get dedicated shards.
  • Cloud inference: free cloud inference with selected models creates embeddings inside Qdrant Cloud.

Integrations

Integrations include LangChain, LangGraph, LlamaIndex, Haystack, CrewAI, Mastra, DSPy and Mem0, per Qdrant's frameworks docs.

Pricing

As of Nov 2026, Free is a 1GB single-node cluster, Standard is usage-based and billed hourly, and Premium needs a minimum spend.

Pros

  • Cloud, Hybrid Cloud and air-gapped Private Cloud options.
  • Granular RBAC for Qdrant Cloud resources.
  • Homepage states "SOC2 & HIPAA compliant".

Cons

  • Standard shows no published dollar price on the pricing page.
  • SSO and private VPC links need Premium.
  • We found no audit logs in its docs.

turbopuffer

Best for large search on object storage

turbopuffer is an object-storage native search engine that pairs vector search with BM25 full-text search and server-side rank fusion.

8.7/10 Visit turbopuffer

turbopuffer says it uses "only object storage for state and NVMe SSD with memory cache for compute".

Why we picked it

Its docs cover hybrid search, with "server-side rank fusion via RRF" and native reranking. Pricing clarity scores 9 because every tier has a published price, enterprise included.

Who it's for

Teams with large or fast-growing indexes that want search costs tied to object storage, not memory.

Standout features

  • Native reranking: set `rerank_by` on the multi-query to score and reorder combined candidates.
  • Filtered search: filters run "against an inverted index" alongside vector and full-text queries.
  • Built-in embedding: the quickstart says "turbopuffer embeds your text on writes and queries".
  • BYOC: deploy into your own AWS, GCP, or Azure account with Standard or Managed BYOC.

Integrations

Optional client-side embedding models include Cohere, Google Gemini and Voyage AI, shown in the turbopuffer quickstart, plus SDKs for Python, TypeScript, Go, Java, Ruby, Rust and C#.

Pricing

As of Nov 2026, launch has a $16/mo minimum usage; scale has a $256/mo minimum; enterprise starts at $4,096/mo with a 35% usage premium.

Pros

  • SOC 2 report and GDPR-ready DPA on every plan.
  • SSO and audit logs start on the scale plan.
  • Per-namespace CMEK and private networking on enterprise.

Cons

  • We found no free tier on its pricing page.
  • Unused minimum amounts don't roll over to next month.
  • We found no RBAC in its docs or pricing page.

Supabase

Best for vectors inside Postgres

Supabase is a Postgres platform that adds vector search through pgvector, with hybrid keyword search and row-level security on results.

8.2/10 Visit Supabase

Supabase calls it "an open source toolkit for developing AI applications using Postgres and pgvector."

Why we picked it

Entry access scores full marks: a Free plan and Pro from $25/mo. Its docs show hybrid search with `tsvector` and `pgvector` in plain Postgres.

Who it's for

Teams already on Postgres that want embeddings next to their app data, auth and permissions.

Standout features

  • Permission-aware search: row-level security can restrict which documents a vector similarity search returns.
  • Embeddings in Edge Functions: generate embeddings using open source models directly in Edge Functions.
  • Self-hosting: run it yourself with the Docker setup or the Supabase CLI.

Integrations

Integrations include OpenAI, Hugging Face, LangChain and LlamaIndex, listed in the Supabase AI and vectors docs.

Pricing

As of Nov 2026, Free is $0, Pro is from $25/mo, Team is from $599/mo and Enterprise is custom.

Pros

  • Team adds SOC 2, ISO 27001 and listed dashboard SSO.
  • Platform audit logs are included on Team and Enterprise.
  • Vectors, auth and app tables share one Postgres database.

Cons

  • Free projects pause after one week of inactivity.
  • We found no customer-managed keys in its pricing page.
  • We found no tenant partitions or reranking in its AI docs.

Upstash Vector

Best for serverless pay per request

Upstash Vector is a serverless vector database billed per request, with hybrid indexes, namespaces and hosted embedding models.

7.5/10 Visit Upstash Vector

Why we picked it

Search scores 9 because hybrid indexes "manage a dense and a sparse index component for you". Entry access is full marks: a free plan plus pay as you go at $0.4 per 100K requests.

Who it's for

Developers on serverless apps who want vector search priced by request, not by cluster.

Standout features

  • Hybrid indexes: one index holds dense and sparse components, so keyword and semantic search share it.
  • Hosted embedding: Upstash "provides some hosted models" so you can upsert and query raw text.

  • SQL-like filters: metadata filters use a syntax that resembles SQL.

Integrations

Integrations include LangChain and LlamaIndex, both documented in Upstash's own docs.

  • Fixed plan adds a 99.9% uptime SLA.
  • Hosted models remove a separate embedding pipeline.

Cons

FAQ

FAQs about vector databases

What is a vector database?

A vector database stores embeddings, the number arrays a model makes from text or images, and returns the items closest to a query. Most on this list also filter by metadata and mix in keyword search, which RAG apps use to fetch the right passages.

Do I need a separate vector database if I already use Postgres?

Not always: pgvector adds vector search to Postgres, and Supabase documents hybrid search with `tsvector` and `pgvector` in one database. A dedicated database adds features we found no Supabase docs for, such as tenant partitions and server-side reranking.

Which vector database is free to start?

Pinecone, Weaviate, Qdrant, Supabase, Upstash Vector and Chroma all list a free tier as of Nov 2026; turbopuffer does not. Supabase pauses free projects after one week idle, and Chroma's free Starter plan comes with $5 in monthly credits.

What is hybrid search in a vector database?

Hybrid search runs a vector search and a keyword search, then fuses the two result lists into one ranking. Every database here documents a form of it, and several fuse results with reciprocal rank fusion (RRF).

Which vector databases can I self-host?

Weaviate, Qdrant, Supabase and Chroma document self-hosting. Pinecone and turbopuffer instead offer BYOC, deployment into your own cloud account. We found only managed cloud for Upstash Vector.
