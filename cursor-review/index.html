THE REVIEW

Why it scores well

Cursor's features page says "Agents use their own computers to build, test, and demo features end to end for you to review." The same agent works across the editor, terminal, Slack and GitHub PRs, with SAML/OIDC SSO on Teams and SCIM and audit logs on Enterprise.

Who it's for

Individual developers who want an agent in the editor, and engineering teams that need SSO and seat controls.

Standout features

  • Cloud agents that build, test and demo features on their own machines.
  • CLI, Slack and GitHub surfaces for the same agent.
  • Bugbot runs AI code review in the background on new PRs.
  • Bugbot custom rules for team best practices.
  • Privacy mode keeps code data out of model training.
  • Third-party models billed separately at API list price.

Integrations

The features page states: "Cursor runs in your terminal, collaborates in Slack, and reviews PRs in GitHub."

FAQ

FAQs about Cursor

Is Cursor free?

Yes. The Free plan costs $0 and includes limited agent and Chat requests, without cloud agents or automations.

Does Cursor support SSO?

Yes, on Teams and Enterprise. The pricing page lists SAML/OIDC SSO for those plans, plus SCIM seat management and audit logs on Enterprise.

Which models can Cursor use?

Plus is limited to Grok models. Premium and above add third-party models, which Cursor bills separately at API list price.

Does Cursor train on my code?

Not with privacy mode on. The pricing page says that when it is enabled, code data is not used for training by Cursor or its model providers.

How do Cursor usage limits work?

Each plan has a usage pool that refreshes weekly. If you hit the limit, you can buy top-offs or wait for the refresh.
