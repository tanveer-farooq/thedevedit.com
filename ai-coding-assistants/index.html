The 7 best AI coding assistants, reviewed

01
Cu

Cursor

Best overall

Cursor is an AI code editor with agents, Tab completions, cloud agents and Bugbot review, and it tops our rubric at 9.7.

9.7/10 Visit Cursor

Why we picked it

Cursor covers all six agent jobs we check. Its Agent can "run terminal commands, and edit code", and its admin controls scored full marks.

Who it's for

Developers and teams who want one editor for completions, local agents and cloud agents.

Standout features

  • Tab: "Tab is Cursor's AI-powered autocomplete" for next edits inside the editor.
  • Cloud agents: agents "run in isolated VMs in the cloud" with full development environments.
  • Bugbot: "Bugbot reviews pull requests" and flags bugs, security issues and code quality problems.

Integrations

Slack and Linear can start cloud agents, as can the Cursor iOS app and Cursor Web.

Pricing

As of Nov 2026, Free gives "Limited agent requests"; Plus is $8/mo with Grok models only; Teams is $30+/user/mo; Enterprise is custom.

Pros

  • Teams includes "SAML/OIDC SSO" and custom chat retention.
  • "Privacy Mode is enabled by default for all team members".
  • Holds a "SOC 2 Type II" attestation and ISO/IEC 27001:2022.

Cons

  • Plus: "Only Grok models are available on this plan".
  • Third-party models are "billed separately by usage".
  • SCIM and audit logs need the custom-priced Enterprise plan.

GitHub Copilot

Best for teams on many editors

GitHub Copilot is an AI pair programmer that runs in VS Code, Visual Studio, Xcode and Eclipse, plus a CLI and a cloud agent.

9.5/10 Visit GitHub Copilot

Why we picked it

Copilot's free plan goes further than most here. The Free plan gives "2,000 completions per month", and Pro is $10/mo.

Who it's for

Teams whose developers use different editors and want one assistant and one admin console.

Standout features

  • Agent mode on Free: "Free plan supports CLI and agent mode", not only completions.
  • Cloud agent: it can "run tests and linters in a cloud development environment" instead of your machine.
  • Code review: "Copilot reviews your pull requests", finds issues and suggests fixes you can apply.

Integrations

The cloud agent works with Microsoft Teams, Slack, Linear, Jira and Azure Boards.

Pricing

As of Nov 2026, Free is $0; Pro is $10/mo; Business is "$19 USD per granted seat per month"; Enterprise is $39 per seat.

Pros

  • Business uses SCIM provisioning, with optional SAML SSO.
  • No training on Copilot Business or Enterprise customer data.
  • Every tier, Enterprise included, has a published seat price.

Cons

  • No retention control or named certification found in Copilot pages.
  • Extra use means you purchase additional AI Credits.
  • The audit log "retains events for the last 180 days" only.

Best for ChatGPT subscribers

OpenAI Codex is a coding agent included with ChatGPT plans, working across the web, a CLI, an IDE extension, iOS and Slack.

9.4/10 Visit OpenAI Codex

Why we picked it

If you already pay for ChatGPT, Codex comes with your plan. Plus includes "Codex on the web, in the CLI, in the IDE extension, and on iOS".

Who it's for

ChatGPT Plus, Business and Enterprise users who want an agent for delegated coding tasks.

Standout features

  • Codex CLI: inspect code, make changes and run commands "without leaving your terminal".
  • Approval modes: "Choose when Codex can edit files or run commands without asking".
  • Cloud integrations: plans include "automatic code review and Slack integration" for cloud tasks.

Integrations

Slack for cloud tasks (pricing page); "VS Code and compatible editors use the Codex extension".

Pricing

As of Nov 2026, Free lets you "Explore Codex capabilities on quick coding tasks"; Go is $8/mo; Plus $20/mo; Business $20/user/mo annual, $25 monthly.

Pros

  • Business has SAML SSO and no training on business data.
  • Enterprise adds audit logs via the Compliance API and SCIM.
  • Enterprise offers "Data retention and data residency controls".

Cons

  • No inline code completions documented, unlike Cursor or Copilot.
  • Enterprise pricing is through sales only.
  • Heavy use needs extra ChatGPT credits beyond the plan.

Claude Code

Best for terminal-first work

Claude Code is Anthropic's agentic coding tool that reads your codebase, edits files and runs commands from terminal to web.

9.3/10 Visit Claude Code

Why we picked it

It scores full marks on surfaces and admin. Claude Code "runs on several surfaces: the terminal, IDE extensions, a desktop app, and the web", and Enterprise adds SCIM, audit logs and custom retention.

Who it's for

Developers who work from the terminal and teams already paying for Claude.

Standout features

  • Git work: it "stages changes, writes commit messages, creates branches, and opens pull requests".
  • Slack hand-off: mention @Claude in Slack "with a bug report and get a pull request back".
  • Parallel agents: a lead agent "coordinates the work, assigns subtasks, and merges results".
  • Hooks: run shell commands before or after actions, such as linting before a commit.

Integrations

VS Code and Cursor extensions, Slack, GitLab CI/CD, and through MCP, Google Drive, Jira and Slack data.

Pricing

As of Nov 2026, Free excludes Claude Code; Pro is $17/mo billed annually or $20 monthly; Team Standard is $20/seat/mo annually; Enterprise adds usage.

Pros

  • Team plans have no model training on your content by default.
  • Holds ISO 27001:2022 and SOC 2 Type II.
  • Same CLAUDE.md, settings and MCP servers on every surface.

Cons

  • The Free plan does not include Claude Code.
  • No inline code completions documented in its docs.
  • Enterprise usage cost scales with model and task.

Kiro

Best for spec-driven development

Kiro is an AWS development environment that plans features as specs, then builds them through one agent across IDE, CLI, web and mobile.

8.4/10 Visit Kiro

Why we picked it

Entry access scores full marks: the Free tier "includes 50 credits per month" and Pro is $20. Specs suit teams that want a plan before code.

Who it's for

Teams on AWS that want requirements, design and tasks written before the agent codes.

Standout features

  • Specs: "Plan a feature with requirements, design, and tasks" before implementation starts.
  • Hooks: "Automate actions on agent file changes, tool use, or task completion".
  • Web agent: a "browser-based agent for multi-repo tasks that plans, implements, and opens PRs".
  • Central governance: admins govern model use, MCP servers and extensions from centralized registries.

Integrations

SSO via Okta, Entra ID and AWS IAM Identity Center; MCP servers; prompt logs to your own Amazon S3 bucket.

Pricing

As of Nov 2026, Free includes 50 credits/mo; Pro is $20/user/mo; teams pay $20/seat/mo with pooled credits; add-on credits cost $0.04 each.

Pros

  • Enterprise content is not used for service improvement.
  • One agent powers IDE, CLI, web and mobile.
  • Security tested under AWS Compliance Programs.

Cons

  • GovCloud pricing runs about 20% higher than commercial regions.
  • Free tier inputs may be stored up to 60 days.
  • No SCIM or retention controls found in its docs.

Cline

Best open-source option

Cline is an open-source coding agent for your editor, terminal, desktop and browser that asks for your approval before every action.

8.2/10 Visit Cline

Why we picked it

Cline is the only pick you can run inside your own network: Enterprise supports VPC, on-prem and air-gapped setups. The extension itself is free, and you "only pay for AI inference credits" when you use models.

Who it's for

Teams that need self-hosting or their own model provider, and developers who want to approve each step.

Standout features

  • Approval on every step: Cline can edit files and run terminal commands, and "every action requires your explicit approval."
  • Editor and terminal: Cline "lives in your editor and your terminal", with a headless CLI for CI/CD scripts.
  • MCP servers: MCP lets Cline "use external tools and data sources" through servers you add.

Integrations

Enterprise connects directly to Amazon Bedrock, GCP Vertex, Azure OpenAI or your own local inference; the extension runs in VS Code and other IDEs.

Pricing

As of Nov 2026, the open-source extension is free and you pay for inference by usage; Enterprise is priced by quote.

Pros

  • Enterprise runs in your VPC, on-prem or air-gapped.
  • Enterprise says "your code is never used to train models".
  • Enterprise includes SSO, SCIM provisioning and audit logs.

Cons

  • No inline completions or PR review documented; Desktop is in beta.
  • No fixed paid plan; inference costs vary with use.
  • No retention controls or named certification found today.

Google Antigravity

Best for Google Cloud teams

Google Antigravity is Google's agent-first coding app, with IDE extensions and a CLI, sold to businesses through Google Cloud.

7.5/10 Visit Google Antigravity

Google now points Gemini Code Assist users to Antigravity, after the Code Assist IDE extensions for individuals stopped serving requests on June 18, 2026.

Why we picked it

Antigravity has a real free plan, "without a subscription plan", with unlimited Tab completions. Business seats are billed under Google Cloud terms, which suits teams already on it.

Who it's for

Teams already billing through Google Cloud or Gemini Enterprise that want one agent across app, IDE and CLI.

Standout features

  • Supercomplete: "provides code suggestions in a region near your current cursor position", not only at the cursor.
  • Browser subagent: the agent "delegates live UI testing, screenshots, and web inspection to the browser subagent."
  • Several surfaces: the desktop app, CLI and IDE extensions share one agent.
  • Enterprise logging: admins can "audit model interactions and maintain enterprise compliance records".

Integrations

Integrations include VS Code, Visual Studio, Zed, Xcode and Eclipse through Antigravity's IDE extensions, plus MCP servers.

Pricing

As of Nov 2026, the individual plan is free; Google AI Pro and Ultra add higher limits. Gemini Enterprise Standard/Plus starts at $30/seat/mo, or pay-as-you-go with a $0 seat fee.

Pros

  • Free plan includes unlimited Tab completions.
  • Business billing gets spend caps across API and subscription plans.
  • Centralized admin controls span the app and CLI.

Cons

  • No cloud agents or PR review documented.
  • Pro and Ultra prices not shown on Antigravity's pricing page.
  • No SCIM, training statement or named certification found.

FAQ

FAQs about AI coding assistants

What is an AI coding assistant?

An AI coding assistant is software that suggests code, edits files and runs commands in your project from a prompt. The newer ones also work as agents that make multi-file changes, open pull requests and review code.

Which AI coding assistant is free?

GitHub Copilot, Cursor, OpenAI Codex, Kiro, Google Antigravity and Cline all have a free option. Copilot Free gives 2,000 completions a month with agent mode, Kiro Free gives 50 credits a month, and Cline's extension is free but you pay for model inference.

Can I self-host an AI coding assistant?

Of the seven, only Cline documents running the whole product in your own environment. Cursor can run cloud-agent tools on self-hosted machines. Its Enterprise plan runs in your VPC, on-prem or air-gapped, and connects to Amazon Bedrock, GCP Vertex, Azure OpenAI or your own local inference.

Is Claude Code included in the Claude Free plan?

No, Claude Code needs a paid plan. As of Nov 2026 Pro costs $17 a month billed annually or $20 monthly, and Team Standard costs $20 a seat a month billed annually.

What happened to Gemini Code Assist for individuals?

Google stopped serving requests from the individual Code Assist IDE extensions on June 18, 2026, and points those users to Google Antigravity. Antigravity has a free individual plan with unlimited Tab completions.
