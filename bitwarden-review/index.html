THE REVIEW

Why it scores well

Bitwarden keeps core password management free, with unlimited stored logins, notes, cards and identities. Business plans start at $4 per user per month and still include SCIM and event logs. Enterprise adds SSO and self-hosting for $6.

Who it's for

IT and security teams that need directory sync and SSO on a tight budget, plus developers who want secrets in the same vendor.

Standout features

  • SSO with any identity provider that uses SAML 2.0 or OpenID Connect.
  • SCIM provisioning and event logs from the Teams plan up.
  • Directory Connector syncs Microsoft Entra ID, Okta, Google Workspace and LDAP.
  • Self-hosting on your own server with Docker and Docker Compose.
  • A full CLI, installed with npm, that covers most client features.
  • Send shares encrypted data with people who don't use Bitwarden.

Integrations

Microsoft Entra ID, Okta, Google Workspace and LDAP or Active Directory for directory sync. Secrets Manager adds GitLab CI/CD, Jenkins and a Kubernetes Operator.

FAQ

FAQs about Bitwarden

Is Bitwarden free?

Yes, Bitwarden's docs say the free plan includes unlimited logins, notes, cards and identities on any device. A free organization also lets you share data with one other user.

Does Bitwarden support SSO?

Yes, on the Enterprise plan, with any identity provider that uses SAML 2.0 or OpenID Connect. Its pricing FAQ says vault decryption stays separate from the identity provider.

Can you self-host Bitwarden?

Yes, self-hosting is an Enterprise plan feature, and the Linux install guide uses Docker and Docker Compose. Bitwarden notes that running it needs technical staff for maintenance, security and updates.

How much does Bitwarden cost for a business?

Teams costs $4 per user per month and Enterprise costs $6, both billed annually. Secrets Manager is priced separately, starting at $6 per user per month on Teams.

Is Bitwarden secure enough for compliance audits?

Bitwarden says it holds ISO 27001, SOC 2 Type II and SOC 3 certifications. Teams and Enterprise plans also keep event logs you can use for audit trails.
