THE REVIEW

Why it scores well

Anthropic calls it "an agentic coding tool that reads your codebase, edits files, runs commands, and integrates with your development tools." The same engine runs on every surface, so project settings carry over, though it loses points for having no free plan.

Who it's for

Developers and small teams who want an agent to plan, edit and commit across many files. Larger companies get SSO on Team and audit logs on Enterprise.

Standout features

  • Git work: "It stages changes, writes commit messages, creates branches, and opens pull requests."
  • A CLAUDE.md file in the project root sets coding rules for every session.
  • Hooks "let you run shell commands before or after Claude Code actions", such as lint before commit.
  • Subagents split work: "A lead agent coordinates the work, assigns subtasks, and merges results."
  • Cloud scheduled tasks "run in the cloud, so they keep running even when your computer is off."

Integrations

MCP servers connect outside tools and data, and a Slack mention can return a pull request. GitLab CI/CD runs automated review, and the editor extension also installs in Cursor.

Pros / cons

Pros:

  • Same engine and settings across terminal, editor, desktop and web
  • Hooks and CLAUDE.md give teams repeatable rules
  • Cloud scheduled tasks run with your computer off
  • Pro plan includes it from $17 a month

Cons:

  • No free plan for Claude Code
  • Desktop app needs a paid subscription
  • SCIM and audit logs only on Enterprise
  • Enterprise adds API-rate usage on top of seats

FAQ

FAQs about Claude Code

Is Claude Code free?

No. Claude Code is not on the Free plan; it starts with Pro at $17 a month billed annually, or "$20 if billed monthly."

Where can I run Claude Code?

In the terminal, IDE extensions, a desktop app and the browser. The overview says "Most surfaces require a" Claude subscription or Anthropic Console account.

Can Claude Code open pull requests?

Yes. It stages changes, writes commit messages, creates branches and opens pull requests, and it can run in CI to review code.

Does Claude Code support SSO?

SSO comes with the Team and Enterprise plans. SCIM and audit logs are listed for Enterprise only.
