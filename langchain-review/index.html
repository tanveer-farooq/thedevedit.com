THE REVIEW

Why it scores well

The LangGraph overview says "LangGraph is a low-level orchestration framework and runtime for long-running, stateful agents." LangSmith adds tracing and evaluation on top, and the LangSmith page says tracing is "framework agnostic and works no matter how you build" your agent. Pricing loses points because usage beyond the included traces is billed on top.

Who it's for

Engineering teams that write agent code and want control over state, branching and human review steps. Teams that want a no-code builder should look elsewhere.

Standout features

  • Interrupts pause graph execution at specific points for human input.
  • LangGraph does not require LangChain, so you can adopt it alone.
  • LangSmith evaluation scores your agent’s outputs against datasets and criteria.
  • LangChain agents can call tools defined on MCP servers.
  • LangGraph is an MIT-licensed open-source library and is free to use.

Integrations

LangChain offers many different provider integrations for chat models. LangSmith traces apps built with the OpenAI SDK, Anthropic SDK, Vercel AI SDK, LlamaIndex or custom code.

Pros / cons

  • Pro: Open-source LangGraph under the MIT license.
  • Pro: Human-in-the-loop pauses built into the graph runtime.
  • Pro: Tracing works with non-LangChain frameworks too.
  • Pro: SOC 2 Type II, HIPAA and GDPR on LangSmith.
  • Con: Usage past included traces adds pay-as-you-go cost.
  • Con: Self-hosting and BYOC need the Enterprise plan.
  • Con: Low-level graph API takes code to learn.
  • Con: No visual no-code builder for business users.

FAQ

FAQs about LangChain

Is LangChain free?

The LangChain and LangGraph libraries are open source, and LangGraph is an MIT-licensed open-source library and is free to use. LangSmith has a $0 Developer plan with 5k base traces a month.

Do I need LangChain to use LangGraph?

No. The LangGraph overview says "LangGraph does not require LangChain."

Does LangSmith work without LangChain?

Yes. The LangSmith page says tracing is "framework agnostic and works no matter how you build" your agent.

Can I self-host LangSmith?

Only on Enterprise. The platform setup docs say "Self-hosted and BYOC are available on the Enterprise plan".

Does LangSmith support SSO?

Yes, on Enterprise. The Enterprise docs list "SAML or OIDC single sign-on" for your identity provider.
