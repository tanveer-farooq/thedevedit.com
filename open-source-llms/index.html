The 7 best open source LLMs for 2026

Open source LLMs are models whose weights you can download, run and fine-tune on your own hardware. We ranked 7 families from publisher model cards and Ollama pages, scoring license terms, capabilities, sizes and local footprint.

Qw

Qwen3

Best all-round open model family

Qwen3 is an Apache 2.0 model family from 0.6B to 235B parameters, with a switchable thinking mode and 131K context.

9.3/10 Visit Qwen3

Why we picked it

Qwen3 earns full marks on license, footprint and availability. The model card is Apache 2.0, and the Ollama library offers eight sizes from 0.6b to 235b.

Who it's for

Teams that want one license and one model family from laptop prototypes to multi-GPU servers.

Standout features

  • Thinking mode: "By default, Qwen3 has thinking capabilities enabled", and you can switch it off.
  • Long context: "32,768 natively and 131,072 tokens with YaRN" on the flagship card.
  • Mixture of experts: the flagship has 235B total parameters with 22B activated.
  • Multilingual: the card claims "Support of 100+ languages and dialects".

Integrations

Hugging Face Transformers, vLLM, SGLang, Ollama, LMStudio, MLX-LM, llama.cpp and KTransformers, per the Qwen3 model card.

Pricing

As of Nov 2026, the weights are free to download under Apache 2.0; you pay only for your own hardware.

Pros

  • Apache 2.0 across the family.
  • Eight Ollama sizes, starting at 0.6B.
  • Thinking mode toggles per request.

Cons

  • The card doesn't state image input.
  • Native context is 32K; 131K needs YaRN.
  • The card doesn't state a GPU memory figure.

gpt-oss

Best for reasoning on one GPU

gpt-oss is an Apache 2.0 reasoning model pair from OpenAI, with a 120B model for one 80GB GPU and a 20B model.

8.6/10 Visit gpt-oss

Why we picked it

gpt-oss earns full marks on license, footprint and availability. The model card states the 120b fits a single 80GB GPU, and the Ollama page lists the 20b at 14GB.

Who it's for

Developers who want an adjustable reasoning model on one data-center GPU or a 16GB machine.

Standout features

  • Configurable reasoning effort: you can "adjust the reasoning effort (low, medium, high)" per use case.
  • Single-GPU fit: the 120b runs "on a single 80GB GPU (like NVIDIA H100 or AMD MI300X)".
  • Sparse model: 117B parameters with 5.1B active parameters.
  • Full chain-of-thought: the card gives complete access to the model's reasoning for debugging.

Integrations

Hugging Face Transformers, vLLM and Ollama, per the gpt-oss model card.

Pricing

As of Nov 2026, the weights are free to download under Apache 2.0; you pay only for your own hardware.

Pros

  • Apache 2.0 with no copyleft terms.
  • The 20b runs within 16GB of memory.
  • Three reasoning effort levels.

Cons

  • The card doesn't state a context length.
  • The card doesn't state image input.
  • Only two sizes, none under 10B.

Mistral Small 3.2

Best for function calling with vision

Mistral Small 3.2 is a 24B Apache 2.0 model from Mistral AI with image input and a more robust function calling template.

8.6/10 Visit Mistral Small 3.2

Why we picked it

Mistral Small 3.2 earns full marks on license, footprint and availability. The model card is Apache 2.0 with vision input, and the Ollama page lists a 15GB download.

Who it's for

Teams building tool-calling agents that also need to read images, on one model.

Standout features

  • Function calling: the card says its "function calling template is more robust" than 3.1.
  • Vision input: the card shows how to "Leverage the vision capabilities" of the model.
  • Fewer repetitions: it "produces less infinite generations or repetitive answers".
  • Stated memory figure: it needs about 55 GB of GPU RAM in bf16 or fp16.

Integrations

vLLM (recommended) and Hugging Face Transformers, per the Mistral Small 3.2 model card.

Pricing

As of Nov 2026, the weights are free to download under Apache 2.0; you pay only for your own hardware.

Pros

  • Apache 2.0 with image input.
  • 15GB Ollama download.
  • Function calling examples on the card.

Cons

  • Only one size, 24B.
  • The card doesn't state a context length.
  • The card doesn't state a thinking mode.

Gemma 3

Best for small multimodal models

Gemma 3 is Google's multimodal open model family, from a 292MB 270M build to a 27B model that runs on one GPU.

8.5/10 Visit Gemma 3

Why we picked it

Gemma 3 scores full marks on size range, footprint and availability. The model card lists a 128K context and image input, and Ollama lists five sizes from 270M to 27B.

Who it's for

Developers who need image input on laptops or a single GPU and accept a custom license.

Standout features

  • Image input: the models handle "text and image input and generating text output".
  • Long context: "Gemma 3 has a large, 128K context window", though the 1B build is shorter.
  • Many languages: the card cites multilingual support in over 140 languages.
  • Single-GPU flagship: Ollama calls 27B "the current, most capable model that runs on a single GPU."

Integrations

The card's usage section shows Hugging Face Transformers, and the Ollama library lists every size.

Pricing

As of Nov 2026, weights are free under Google's Gemma usage license, which you must accept on Hugging Face.

Pros

  • Five sizes, from 270M to 27B.
  • Smallest Ollama download is 292MB.
  • Text and image input from 4B up.

Cons

  • Custom license must be accepted before download.
  • The card doesn't state a thinking mode.
  • The 1B model's context is 32K, not 128K.

Phi-4

Best compact MIT-licensed model

Phi-4 is Microsoft's 14B dense text model under the MIT license, trained heavily on synthetic data and shipped as a 9.1GB Ollama download.

8.4/10 Visit Phi-4

Why we picked it

Phi-4 earns full marks on license, footprint and availability. The model card lists MIT terms, and Ollama's single 14B build is 9.1GB.

Who it's for

Teams that want permissive terms and a mid-size model for memory-limited or latency-bound apps.

Standout features

  • Permissive license: MIT, with no usage caps or acceptance gate on the card.
  • Dense 14B design: "14B parameters, dense decoder-only Transformer model".
  • Synthetic training data: built on a "blend of synthetic datasets, data from filtered public domain websites" and books.
  • Constrained targets: the card names memory/compute constrained and latency-bound scenarios as primary uses.

Integrations

The card's usage example uses Hugging Face Transformers, and the Ollama library lists a 14B build.

Pricing

As of Nov 2026, weights are free under the MIT license.

Pros

  • MIT license with no acceptance gate.
  • Ollama download is only 9.1GB.
  • Card lists reasoning and logic as a primary use.

Cons

  • Context is 16K tokens, shortest in this list.
  • Text only; the card lists no image input.
  • Only one size, and no stated GPU figure.

DeepSeek-V3.1

Best large MIT model for servers

DeepSeek-V3.1 is an MIT-licensed 671B model with 37B active parameters that runs thinking and non-thinking modes in one checkpoint.

8.3/10 Visit DeepSeek-V3.1

Why we picked it

It pairs a full-marks license with strong published results. The card states the weights are "licensed under the MIT License" and reports 66.0 on SWE Verified in agent mode.

Its size is the trade-off.

Who it's for

Teams with multi-GPU servers who want a permissively licensed model for coding and agent work.

Standout features

  • Hybrid thinking: "One model supports both thinking mode and non-thinking mode" by changing the chat template.
  • Tool calling: the card says tool usage and agent tasks improved through post-training optimization.
  • 128K context: the model table lists 671B total, 37B activated and a 128K context length.
  • FP8 weights: trained with the UE8M0 FP8 scale format on weights and activations.

Integrations

Hugging Face Transformers, per the model card's usage section, and an Ollama library build.

Pricing

As of Nov 2026, the weights are free to download under the MIT License.

Pros

  • MIT license covers code and weights.
  • One checkpoint handles thinking and non-thinking chat.
  • Published agent coding scores beat DeepSeek R1 0528.

Cons

  • The Ollama 671b download is 404GB.
  • No small sizes ship in this family.
  • The card doesn't state minimum GPU requirements.

Llama 4

Best for very long context

Llama 4 is Meta's natively multimodal model family, with Scout offering a 10M-token context window and fitting one H100 at int4.

7.8/10 Visit Llama 4

Why we picked it

Scout's 10M context is the longest on this list. The card says Scout "can fit within a single H100 GPU with on-the-fly int4 quantization".

Its custom license costs it points.

Who it's for

Developers who need long-document or multi-image input and can accept Meta's license terms.

Standout features

  • Two sizes: Scout uses 16 experts and Maverick 128, both with 17B active parameters.
  • Native multimodality: "natively multimodal AI models that enable text and multimodal experiences".
  • 12 languages: the card lists Arabic, English, French, German, Hindi, Spanish, Thai and more.
  • Quantized releases: Maverick ships as both BF16 and FP8 quantized weights.

Integrations

Hugging Face Transformers, per the model card, and Ollama builds of both sizes.

Pricing

As of Nov 2026, the weights are free under the Llama 4 Community License Agreement.

Pros

  • Scout offers a 10M-token context window.
  • Scout fits one H100 with int4.
  • Text and image input in both sizes.

Cons

  • Services above 700M monthly users need Meta's license.
  • Custom license, not Apache 2.0 or MIT.
  • Smallest Ollama download is still 67GB.

FAQ

FAQs about open source LLMs

What is an open source LLM?

An open source LLM is a language model whose weights the publisher releases for download, so you can run and fine-tune it yourself. Licenses vary: Qwen3, gpt-oss and Mistral Small 3.2 use Apache 2.0, Phi-4 and DeepSeek-V3.1 use MIT, and Gemma 3 and Llama 4 use custom terms.

Which open source LLM runs on a laptop?

Gemma 3, Qwen3 and Phi-4 have the smallest local downloads on this list. Gemma 3's 270M build is 292MB on Ollama, Qwen3 starts at 0.6B, and Phi-4's single 14B build is 9.1GB.

Can I use open source LLMs commercially?

Usually yes, but check each license. Apache 2.0 and MIT models carry few conditions, Gemma 3 requires accepting Google's terms on Hugging Face, and Llama 4 services above 700M monthly users need a license from Meta.

Which open source LLM has the longest context window?

Llama 4 Scout has the longest, with a 10M-token context window. Qwen3 reaches 131K tokens with YaRN, while Gemma 3 and DeepSeek-V3.1 list 128K and Phi-4 lists 16K.

Do I need a GPU to run an open source LLM?

Not for the smallest models, but larger ones need serious GPUs. gpt-oss-120b fits one 80GB GPU, Mistral Small 3.2 needs about 55 GB of GPU RAM in bf16, and DeepSeek-V3.1's Ollama download is 404GB.
