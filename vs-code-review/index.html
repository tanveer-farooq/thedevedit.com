# VS Code review

Visual Studio Code is a free code editor from Microsoft. This review is docs-based: we scored it 9.1 /10 from its official documentation, with no hands-on testing.

By TheDevEdit Editorial Team · Docs-based review · Prices checked Nov 15, 2026

OVERVIEW

What VS Code is

The VS Code FAQ says "Visual Studio Code is a distribution of the Code - OSS repository with Microsoft specific customizations." It adds "The source code is available to everyone under a standard MIT license."

The latest release on the updates page is Visual Studio Code 1.146, dated November 11, 2026.

OUR VERDICT

If your team wants one free editor that covers most languages, start with VS Code. On our documentation rubric it scored 9.1, mainly for remote development, admin policies and its free licence, and lost points because extensions run with full editor permissions.

WHAT WE LIKED

  • \+ Free for private or commercial use, with MIT-licensed source
  • \+ Signed marketplace extensions, plus an allow-list for organizations
  • \+ Remote work over SSH, containers, WSL and tunnels
  • \+ Agents, MCP servers and bring-your-own-key models

WHAT HELD IT BACK

  • – The browser version has no terminal or debugger
  • – Extensions have the same permissions as the editor itself
  • – Telemetry is on until you turn it off

Key features

Extensions

The marketplace docs say "Extensions add languages, debuggers, and tools to Visual Studio Code to support your development workflow." They also warn "Extensions have the same permissions as VS Code itself."

When the allow-list is set, the same page says "all extensions not listed are blocked from installing."

Languages and debugging

On the languages overview, "Several ship in the box, for example, JavaScript, TypeScript, CSS, and HTML." Other languages come from marketplace extensions.

For runtimes beyond JavaScript, the debugging docs say "For other languages and runtimes, install a debugger extension."

Remote development

The remote overview says Remote Development lets you "use a container, remote machine, or the Windows Subsystem for Linux" as a full environment. The extension pack lists Remote - SSH, Dev Containers, WSL and Remote - Tunnels.

AI agents

The AI overview says "An agent uses a model and tools to find relevant code, make changes, and run checks." You can "Choose models from multiple providers through GitHub Copilot, or use your own API key (BYOK) or a supported local model."

Enterprise policies

The enterprise docs say "VS Code supports centrally managed policies that override user settings on managed devices." They add "Policies can be deployed through device management solutions like Microsoft Intune."

VS Code for the Web

The web docs say it runs "entirely in your browser." The trade-off: "For example, the terminal and debugger are not available."

FAQ

FAQs about VS Code

Can I turn off VS Code telemetry?

Yes. The FAQ says "VS Code collects usage data and sends it to Microsoft" by default, and to "set the Telemetry: Telemetry Level setting to off" to stop it.

How often does VS Code update?

Stable builds auto-update on macOS and Windows. The FAQ says "The Insiders build is updated nightly so you'll get the latest bug fixes and feature updates from the day before."

Can admins block extensions?

Yes. The marketplace docs say that once extensions.allowed is set, "all extensions not listed are blocked from installing."

What hardware does VS Code need?

The requirements page says "Visual Studio Code is a small download (< 200 MB) and has a disk footprint of < 500 MB." It recommends a 1.6 GHz processor and 1 GB of RAM.
