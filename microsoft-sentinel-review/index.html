THE REVIEW

Why it scores well

Microsoft's overview calls it "a cloud-native SIEM solution that delivers scalable, cost-efficient security across multicloud and multiplatform environments." It adds a managed data lake for long retention, playbooks on Azure Logic Apps and free ingestion for core Microsoft logs.

Who it's for

SOC teams and MSSPs that run on Azure, Microsoft 365 and Defender. Teams with no Azure footprint take on a new cloud just to run it.

Standout features

  • Connectors for Microsoft sources, plus common event format, Syslog and REST-API for other tools
  • Analytics rules that group related alerts into incidents to cut review noise
  • MITRE ATT&CK coverage view based on your ingested data
  • Data lake tier that keeps security data "for up to 12 years"
  • Jupyter notebooks in Azure Machine Learning for custom analysis

Integrations

Microsoft Entra ID, Azure Activity, Office 365 and the Defender family connect natively. The automation docs say "playbooks are based on workflows built in Azure Logic Apps," which connects playbooks to other systems.

FAQ

FAQs about Microsoft Sentinel

Is Microsoft Sentinel free?

No, but it has a free trial: the billing docs say "the first 10 GB/day ingested using the Analytics logs plan is free for 31 days." Azure Activity and Office 365 audit logs stay free after the trial.

How much does Microsoft Sentinel cost per GB?

Pay-as-you-go analytics ingestion lists at $4.30 per GB in US East as of Nov 2026. Commitment tiers start at 100 GB a day for $296, and prices vary by region and agreement.

How long does Microsoft Sentinel keep data?

Analytics-tier data is kept free for the first 90 days. The data lake tier is built for retention "for up to 12 years," billed per GB stored each month.

Is Microsoft Sentinel moving out of the Azure portal?

Yes. Microsoft says support in the Azure portal ends on March 31, 2027, after which Sentinel runs only in the Microsoft Defender portal.

Does Microsoft Sentinel work outside Azure?

Yes, for data sources. It ingests logs through common event format, Syslog and REST-API connectors, and its SAP solution covers systems on Azure, GCP, AWS or on-premises.
