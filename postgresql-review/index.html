# PostgreSQL review

Free, open source object-relational database from the PostgreSQL Global Development Group. This review is docs-based: we scored it from postgresql.org's documentation and release notes, with no hands-on testing.

9.7 /10 our score (docs-based)

OVERVIEW
OUR VERDICT

PostgreSQL is a free, open source database that fits teams needing one general-purpose SQL store for transactions, JSON and full-text search. It scores 9.7 on our docs rubric, and the main costs are planned major upgrades and a 5-year support window per version.

PostgreSQL's about page calls it an "open source object-relational database system that uses and extends the SQL language." The same page says it has been ACID-compliant since 2001 and "runs on all major operating systems".

  • \+ Document, range, geometry and custom types sit beside standard SQL types, with JSON/JSONB and full-text search built in
  • \+ Write-ahead logging, synchronous and logical replication, and point-in-time recovery are all core features
  • \+ Extensions, foreign data wrappers and procedural languages let you add features without forking the database
  • \+ PostgreSQL 18 added asynchronous I/O, which the project says benchmarks showed "performance gains of up to 3x in certain scenarios"
  • – Major-version upgrades need a dump and restore, pg_upgrade or logical replication
  • – Each client connection gets its own server process, and no built-in pooler is listed on the pages we checked
  • – Each major version is supported for 5 years, so long-lived systems must plan upgrades

What PostgreSQL does well

Data types. The about page lists JSON/JSONB, XML, Hstore key-value, arrays, ranges, UUIDs and geometric types. You can also define composite and custom types.

Extensions and other languages. The about page says you can "define your own data types, build out custom functions, even write code from different programming languages without recompiling your database." Core procedural languages are "PL/pgSQL, Perl, Python, and Tcl."

Foreign data. PostgreSQL's foreign data wrappers "connect to other databases or streams with a standard SQL interface."

Security. The feature list names SCRAM-SHA-256, LDAP, certificate and OAuth 2.0 authentication, plus "Column and row-level security." PostgreSQL 18's release notes say it "introduces oauth authentication."

What's new in PostgreSQL 18

  • Asynchronous I/O: a new AIO subsystem aimed at faster reads from storage.
  • uuidv7(): PostgreSQL 18 also adds UUIDv7 generation through the uuidv7() function, giving timestamp-ordered UUIDs.
  • Upgrade statistics: PostgreSQL 18 can "keep planner statistics through a major version upgrade," so queries recover speed sooner after upgrading.

Where it falls short

Upgrades. PostgreSQL's upgrade docs say "the internal data storage format is subject to change, thus complicating upgrades" for major releases. For pg_upgrade, the same page says "Upgrades can be performed in minutes, particularly with --link mode."

Connections. The connection docs state "PostgreSQL implements a "process per user" client/server model." The core pages we checked list no built-in connection pooler, while Azure's managed service ships one.

Hard limits. The limits table caps a field at 1 GB and a relation at 32 TB with the default block size. A table holds at most 1,600 columns.

COMMUNITY POSTGRESQL · $0 Free to download and use. The PostgreSQL License is "a liberal Open Source license, similar to the BSD or MIT licenses."

SELF-HOSTED · your infrastructure cost Packages and installers for Linux, macOS, Windows and BSD on the download page. You pay only for servers, storage, backups and staff time, so we give no fixed figure.

MANAGED CLOUD · billed by the provider Azure Database for PostgreSQL says "You can build your first application on a small database for a few dollars a month." Larger compute tiers cost more.

The license never costs money, so your real cost is compute, storage and operations. Self-hosting trades a lower bill for upgrade, backup and failover work; a managed service charges to take that work on.

FAQ

FAQs about PostgreSQL

Is PostgreSQL free for commercial use?

Yes. The PostgreSQL License grants permission to "use, copy, modify, and distribute this software and its documentation for any purpose, without fee," as long as the copyright notice is kept.

What is the latest PostgreSQL version?

PostgreSQL 18.7, released November 12, 2026, alongside 19 RC 2. PostgreSQL 19 was still a release candidate when we checked.

How long is a PostgreSQL version supported?

Five years. The versioning policy says "The PostgreSQL Global Development Group supports a major version for 5 years after its initial release." PostgreSQL 14 reaches its final release on November 12, 2026, and PostgreSQL 18 on November 14, 2030.

How often does PostgreSQL ship fixes?

At least quarterly. Minor releases carrying bug and security fixes are "released at least once every three months," per the versioning policy, and they never change the storage format.
