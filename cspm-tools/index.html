Prowler

Best open source CSPM

Prowler is an open source CSPM with thousands of checks, 70+ compliance frameworks and a hosted cloud option.

9.5/10 Visit Prowler

Why we picked it

Prowler takes full marks on cloud coverage, deployment options and entry access. It runs as free open source, a self-hosted web app or Prowler Cloud, and the pricing page publishes a per-account price.

Who it's for

Cloud security teams that want open source posture checks they can self-host, with a managed option later.

Standout features

  • Ready-made checks: the docs promise "thousands of ready-to-use security checks" across providers.
  • Compliance mapping: Prowler Cloud offers continuous compliance across 70+ frameworks.
  • Kubernetes and IaC providers: both are "Official" providers, covering clusters and repositories.
  • Self-hosting: Prowler Local Server is a "Self-hosted web application and API."

Integrations

Integrations include Jira, Slack, Power BI, email and custom SIEM export, with SAML SSO through Okta and Entra ID, per Prowler's pricing page.

Pricing

As of Nov 2026, Prowler Open Source is free, Prowler Cloud is $99 per cloud account per month, and Private Cloud is custom.

Pros

  • Open source edition is "free, forever."
  • Covers AWS, Azure, Google Cloud, Kubernetes and IaC.
  • SAML SSO for multiple domains on Prowler Cloud.

Cons

  • We found no vulnerability scanning in its docs.
  • Private Cloud pricing is custom only.
  • Cloud pricing scales with every connected cloud account.

Microsoft Defender for Cloud

Best for Azure-led multicloud

Microsoft Defender for Cloud is a CSPM with a free Foundational plan and a paid tier covering Azure, AWS and GCP.

8.7/10 Visit Microsoft Defender for Cloud

Why we picked it

Defender for Cloud scores full marks on cloud coverage and 9 on workflow and admin. Its CSPM docs cover Azure, AWS, GCP and on-premises resources through Azure Arc, with data exporting and workflow automation in both plans.

Who it's for

Security teams running mostly on Azure that also need posture checks for AWS and GCP accounts.

Standout features

  • Free Foundational CSPM: "Available at no cost", with secure score and security recommendations.
  • Attack path analysis: the paid Defender CSPM plan adds attack path analysis and risk prioritization.
  • Agentless scanning: Defender CSPM lists agentless VM vulnerability scanning and agentless discovery for Kubernetes.
  • Hybrid coverage: "On-premises resources connected through Azure Arc" get posture checks too.

Integrations

Integrations include ServiceNow (preview), Azure DevOps, GitLab, Docker Hub and JFrog Artifactory, per Microsoft's CSPM docs.

Pricing

As of Nov 2026, Foundational CSPM is free; Defender CSPM is billed per covered resource, such as VMs, storage accounts and databases.

Pros

  • Free plan includes data exporting and workflow automation.
  • Covers Azure, AWS, GCP and Arc-connected on-premises servers.
  • Regulatory compliance assessments come with Defender CSPM.

Cons

  • We found no self-hosted or open source option.
  • Defender CSPM per-resource rate was not readable today.
  • Attack paths and compliance assessments need the paid plan.

Powerpipe

Best for compliance benchmarks as code

Powerpipe is an open source benchmarks-as-code tool running 5,000+ compliance controls from your CLI or a local dashboard.

8.5/10 Visit Powerpipe

Why we picked it

Powerpipe is free and open source, ships "5,000+ open-source controls from CIS, NIST, PCI, HIPAA, FedRamp and more," and publishes every hosted price. It scores full marks on cloud coverage, deployment options and pricing clarity, with AWS, Azure, GCP and Alicloud named on its site.

Who it's for

Engineers who want compliance checks as code they can run locally or in CI.

Standout features

  • Benchmarks as code: 5,000+ open source controls across CIS, NIST, PCI, HIPAA and FedRAMP.
  • Local dashboards: a locally hosted web UI to filter, group, pivot and snapshot results.
  • CLI runs: run benchmarks from the command line, which suits CI pipelines.
  • Hosted option: Turbot Pipes runs it as SaaS, free for developers.

Integrations

Integrations include Slack, Microsoft Teams, Jira, ServiceNow, Zendesk, Opsgenie, Trello and Docker, per Powerpipe's site.

Pricing

As of Nov 2026, Powerpipe is open source; Turbot Pipes Developer is free, Team $49/month, Enterprise $249/month.

Pros

  • Open source core costs nothing.
  • Every hosted plan price is published.
  • Enterprise adds SAML 2.0 single sign-on.

Cons

  • Most controls are compliance checks, not risk prioritization.
  • We found no runtime or vulnerability scanning in its docs.
  • Teams build their own alerting around benchmark runs.

Datadog Cloud Security

Best for Datadog monitoring users

Datadog Cloud Security is a CSPM inside Datadog that tracks compliance posture and attack paths across AWS, Azure and GCP.

7.8/10 Visit Datadog Cloud Security

Why we picked it

Datadog scores well on posture coverage, cloud coverage and entry access. Its docs show a posture score, Security Graph attack paths and agentless scanning, and the DevSecOps Pro price is published.

Who it's for

Teams already monitoring hosts in Datadog that want posture findings in the same platform.

Standout features

  • Posture score: the share of your environment that "satisfies all of your active" compliance rules.
  • Security Graph: used "to investigate supported attack-path findings" with a context graph.
  • Compliance mapping: DevSecOps Pro includes built-in mapping of resources to compliance frameworks for audits.
  • Vulnerability management: DevSecOps Pro covers vulnerabilities in containers and hosts.

Pricing

As of Nov 2026, DevSecOps Pro is $22 per host per month billed annually, or $27 on-demand; it bundles Infrastructure Pro.

Pros

  • Posture findings sit next to existing Datadog monitoring.
  • Entry price per host is published.
  • Bundle adds CIEM and Kubernetes posture management.

Cons

  • We found no free tier on its pricing page.
  • We found no standalone Cloud Security price today.
  • We found no named ticketing integrations in its docs.

AWS Security Hub

Best for AWS-first teams

AWS Security Hub is AWS's native posture service, with attack path analysis, exposure findings and posture checks that reach Azure resources.

7.5/10 Visit AWS Security Hub

Why we picked it

Security Hub scores full marks on pricing clarity. The pricing page shows a worked per-resource-unit example, and the features page covers attack paths, exposure findings and Azure checks.

Who it's for

Teams whose workloads live mostly in AWS and want posture findings inside the AWS console.

Standout features

  • Attack path analysis: it shows "how an adversary could chain together vulnerabilities".
  • Exposure findings: "Security Hub automatically generates exposure findings" from correlated signals.
  • Azure coverage: it runs "posture checks against CIS Azure Foundations Benchmark" on Azure resources.
  • Ticketing: findings route to "ticketing systems, including Jira Cloud and ServiceNow".

Integrations

Integrations include Jira Cloud, ServiceNow, CrowdStrike, SentinelOne, Okta, Zscaler, Proofpoint and Splunk, per AWS's Security Hub features page.

Pricing

As of Nov 2026, Essentials is priced per resource unit, $3.75 in AWS's worked example; a 30-day free trial covers Essentials.

Pros

  • 30-day free trial includes Essentials plan capabilities.
  • Lambda functions count as 1/12 of a resource unit.
  • Jira Cloud and ServiceNow ticketing are built in.

Cons

  • We found no Google Cloud support in its docs.
  • We found no self-hosted option in its docs.
  • Threat analytics and code scanning are separate add-ons.

Google Security Command Center

Best for Google Cloud teams

Google Security Command Center is Google Cloud's native posture service, with a free Standard tier and benchmark-mapped detectors.

7.2/10 Visit Google Security Command Center

Why we picked it

The service tiers docs say "The Standard tier is offered at no additional charge," and its detectors map to NIST, HIPAA, PCI-DSS and CIS. It scores 8 on cloud coverage, free and entry access and pricing clarity; we scored the Standard tier.

Who it's for

Teams running mostly on Google Cloud that want posture checks without adding another vendor.

Standout features

  • Free Standard tier: misconfiguration findings for Google Cloud at no added charge.
  • Benchmark mapping: Security Health Analytics detectors "map to the controls of common security benchmarks like NIST, HIPAA, PCI-DSS, and CIS."
  • Attack path simulation: it maps "the paths that a potential attacker could take to reach your high-value resources."
  • Multicloud on Enterprise: Enterprise covers "Google Cloud, AWS, and Azure" but shuts down May 21, 2027.

Integrations

Findings export to BigQuery and Pub/Sub on every tier, Cloud Logging on Premium and Enterprise, and Enterprise adds Google SecOps SIEM and SOAR, per Google's service tiers docs.

Pricing

As of Nov 2026, Standard is free; Premium is billed pay-as-you-go or by subscription. We could not read published Premium rates.

Pros

  • Standard tier costs nothing extra.
  • Detectors map to NIST, HIPAA, PCI-DSS and CIS.
  • No agent or separate vendor for Google Cloud.

Cons

  • Enterprise tier, the multicloud option, shuts down May 2027.
  • We found no readable Premium price list.
  • We found no ticketing integrations in its tier docs.

FAQ

FAQs about CSPM tools

What is a CSPM tool?

A CSPM tool continuously checks your cloud accounts for misconfigurations and compliance gaps. It maps findings to frameworks such as CIS, NIST and PCI-DSS, and most tools here also add attack path analysis, Kubernetes posture or IaC scanning.

Which CSPM tools are free?

Prowler Open Source and Powerpipe are free and open source as of Nov 2026. Microsoft Defender for Cloud includes free Foundational CSPM, Google Security Command Center Standard is free, and Turbot Pipes has a free Developer plan.

What is the best open source CSPM tool?

Prowler scores highest on our rubric at 9.5/10. It ships thousands of checks across AWS, Azure, Google Cloud, Kubernetes and IaC, and can run self-hosted or as Prowler Cloud. Powerpipe is the alternative for compliance benchmarks as code.

Which CSPM tool is best for multicloud?

Microsoft Defender for Cloud scores full marks on cloud coverage, covering Azure, AWS, GCP and on-premises resources through Azure Arc. Prowler, Powerpipe and Datadog Cloud Security also document all three major clouds.
